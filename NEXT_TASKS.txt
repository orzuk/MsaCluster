Three types of negative controls needed (from paper_scientific_issues.txt):

[CTRL-1] Porter 2022 IDP Controls -- DONE (pipeline ready, not yet run)
  99 intrinsically disordered proteins from DisProt (Porter & Looger 2022).
  Directory setup: scripts/setup_porter_idp.py -> Pipeline/Controls/PorterIDP/
  Pipeline: run_controls_pipeline.py handles all stages (get_msa, cluster,
  AF, ESMFold, postprocess with cluster diversity metric).
  Run:
    python run_controls_pipeline.py --run_mode full_pipeline --protein_ids ALL \
           --control_type PorterIDP --run_job_mode sbatch
  Expected result: low cluster structural diversity (no fold switching).

[CTRL-2] Matched Single-Fold Proteins -- DONE (setup script created, not yet run on all)
  For each fold-switching pair, find single-fold protein from same Pfam family.
  Setup: scripts/setup_matched_controls.py -> Pipeline/Controls/MatchedSingleFold/
  Queries PDBe SIFTS (PDB→Pfam), InterPro (Pfam→members), UniProt (details+PDB xrefs).
  Selection: same Pfam, length ±30%, >30% seq identity, exactly 1 PDB structure.
  Caches API responses to data/cache/. Reference CSV: data/matched_controls.csv.
  Run setup:
    python scripts/setup_matched_controls.py                 # all 93 pairs
    python scripts/setup_matched_controls.py --pair-id 1dzlA_5keqF  # one pair
  Run pipeline:
    python run_controls_pipeline.py --run_mode full_pipeline --protein_ids ALL \
           --control_type MatchedSingleFold --run_job_mode sbatch
  Expected result: high TM-scores across clusters (no fold switching).
