PURPOSE
-------
MsaCluster studies fold-switching proteins -- homologous proteins that adopt
different 3D structures. It builds deep MSAs seeded by protein pairs with
different folds, clusters them into sub-alignments, predicts structures per
cluster (AF2/AF3/ESMFold/ESM3), evaluates contact maps (MSA-Transformer,
CCMpred), builds phylogenetic trees, and computes energetics (Delta-G).

DATASET: 93 protein pairs (full) or 10 pairs (test).
FORMAT:  <pdb1><chain>_<pdb2><chain>  e.g. "1dzlA_5keqF"

================================================================================
PIPELINE STAGES (run_foldswitch_pipeline.py --run_mode <mode>)
================================================================================

 Mode              Description                                  Key Function
 ----              -----------                                  ------------
 load              Download PDB, extract seq+contacts           load_seq_and_struct()
 get_msa           Build deep MSA via ColabFold/MMseqs2         run_getMSA.py
 cluster_msa       Partition deep MSA into shallow clusters     run_ClusterMSA.py
 tree              Build UPGMA phylogenetic tree                phytree_from_msa()
 run_AF            Run AF2/AF3 per chain per cluster            (SLURM or local)
 run_cmap_esm      MSA-Transformer contact maps                 run_MSATrans.py
 run_cmap_ccmpred  CCMpred contact maps                         (external tool)
 run_esmfold       ESMFold/ESM3 structure prediction            run_ESMFoldHF.py
 compute_deltaG    PyRosetta energy calculations                energy_utils.py
 postprocess       Compute TM-scores, build result tables       postprocess_unified.py
 plot              Generate all visualizations                  protein_plot_utils.py
 msaclust_pipeline Run full sequence (all above)                (chained)
