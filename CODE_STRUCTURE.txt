PURPOSE
-------
MsaCluster studies fold-switching proteins -- homologous proteins that adopt
different 3D structures. It builds deep MSAs seeded by protein pairs with
different folds, clusters them into sub-alignments (fine + coarse, phylo-tree
based by default), predicts structures per cluster (AF2/AF3/ESMFold/ESM3/
ESMFold2/Boltz-2/AlphaFlow/BioEmu), evaluates contact maps (MSA-Transformer,
CCMpred), predicts per-cluster secondary structure (S4PRED), builds
phylogenetic trees with ancestral reconstruction, computes energetics
(ThermoMPNN-based DDG and PyRosetta Delta-G), and runs cross-method concordance
analysis with sequence-divergence correction + BH FDR control on the resulting
candidate clade-level fold-switching families. A parallel class-level analysis
asks whether the fold-switch signal differs by trigger type.

DATASET: 93 protein pairs (full) or 10 pairs (test).
FORMAT:  <pdb1><chain>_<pdb2><chain>  e.g. "1dzlA_5keqF"

Controls: 100 IDP (Porter & Looger 2022), 48 Pfam-matched single-fold,
          101 random single-chain PDB. Total 249 controls.

DATA SOURCE OF TRUTH: The cluster (Moriah/glacier) holds the authoritative
  Pipeline/FoldPairs/ data. The local Windows machine has an old, partial copy.
  The local repo is authoritative for CODE only. See NEXT_TASKS.txt.

Concordance scripts are N-method parameterized: --methods / --out-suffix.
Default 8-method run = AF2, AF3, ESM, MSAT, CCMpred, DDG, Boltz2, BioEmu
(the "_8method" CSV suffix). Adding S4PRED gives the 9-method variant.
The KaiB K=100 pilot (treek100_*) is a separate per-pair tree-clustering
experiment; its CSVs live in docs/ alongside the main survey.
